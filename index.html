5 Steps to Connect
  1. Create a Google Sheet at sheets.google.com → blank. Copy the ID from the URL (between /d/ and /edit).
  2. Create a Drive folder named SMH Photos. Copy its folder ID from the URL.
  3. In the Sheet: Extensions → Apps Script. Delete everything in Code.gs, click Copy at top-right of the code box → paste → save.
  4. At the top of the pasted code, replace PASTE_SPREADSHEET_ID_HERE and PASTE_DRIVE_FOLDER_ID_HERE with your two IDs.
  5. Deploy → New deployment → Web app: Execute as Me, Who has access Anyone → Deploy → copy the /exec URL.
  6. Paste that /exec URL into the field on the left → Save & Connect. All 10 sheets, headers and formatting are created automatically on first sync.
Single file — zero dependencies This index.html is the entire app. No Node, React, Firebase or hosting needed. Just open it in a browser and paste your Apps Script URL — done.
